## 📲 Hướng Dẫn Cài Đặt File APK Trên Android

Nếu điện thoại của bạn hiển thị cảnh báo khi cài đặt file APK từ bên ngoài, vui lòng thực hiện:

1. **Bước 1:** Mở file APK vừa tải về từ thông báo hoặc ứng dụng **Tệp (Files)** trên máy.
2. **Bước 2:** Khi có thông báo *"Vì lý do bảo mật, điện thoại không được phép cài đặt ứng dụng không xác định từ nguồn này"*:
   * Bấm vào **Cài đặt (Settings)**.
   * Bật công tắc **"Cho phép từ nguồn này" (Allow from this source)**.
3. **Bước 3:** Nhấn nút **Quay lại (Back)** $\to$ Bấm **Cài đặt (Install)** hoặc **Cập nhật (Update)** để hoàn tất.
